# Calculation Register

Each row is one calculation rule as the code applies it. Rows were written from the code on 2026-11-12; nothing was run. Source paths in the "Where" column are relative to `backend/MicroLIMS.Application/`.

How to read the columns:

- **Rule as coded** states inputs, order of operations and the comparison operator exactly as written in the method. `<` and `<=` are not interchangeable.
- **Rounding and precision** states the rounding call as coded. A call with no mode uses the .NET default (to even). It also says whether the comparison with a limit happens before or after rounding.
- **Configured or coded** says, for the numbers in the rule, whether each one is a literal in the code or read from configuration (the entity and property are named).
- **Reference (pointer)** is a chapter pointer only where the code names one. The register never states that the code matches a chapter. Every reference is "Reference to be confirmed by QA".
- Where two sites disagree, the row links the conflict in `documents/Conflicts.md`.
